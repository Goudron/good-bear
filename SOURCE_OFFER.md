# Сборка Good Bear из исходных материалов

Этот репозиторий содержит только исходные изменения Good Bear: упорядоченные
патчи, overlay-файлы, скрипты сборки, русскую локализацию и оригинальные
иллюстрации. Полный исходный код Firefox здесь намеренно не дублируется.

`tools/bootstrap_public_source.sh` скачивает строго закреплённый архив Firefox,
проверяет его SHA-256, создаёт рабочее дерево и применяет все патчи из
`patches/series`. Он также получает только локаль `ru` из точного detached
commit Mozilla `firefox-l10n`, проверяет хеши двух замещаемых upstream-файлов,
отсутствие двух добавляемых файлов и хеши всех четырёх файлов публичного Good
Bear Fluent overlay. Затем скрипт получает сертификаты только с закреплённых
официальных адресов и проверяет хеши, роль CA и цепочки до включения в локальные
входы сборки. Сертификаты не коммитятся в этот репозиторий и не загружаются во
время работы браузера.

Требования: Ubuntu с зависимостями из `build/ubuntu/install-packages.sh`, а
также `curl`, `python3`, `git`, `openssl` и `sha256sum`.

Подготовить исходное дерево:

```bash
git clone https://github.com/Goudron/good-bear.git
cd good-bear
./tools/bootstrap_public_source.sh
```

Подготовить и собрать русскоязычный кандидат для Linux:

```bash
./tools/bootstrap_public_source.sh --build
```

Скрипт намеренно останавливается при несовпадении хеша Firefox, сертификата,
идентичности CA или цепочки. Выпускной архив содержит только локаль `ru`.
